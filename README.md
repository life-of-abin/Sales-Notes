# Sales-Notes (Vyapaar)

A modern, simple, and user-friendly Sales, Inventory, Expenses, and Profit Management Progressive Web App (PWA) tailored for small businesses and merchants.

## ✨ Features

- **📊 Dashboard & Metrics**: Real-time sales, net profit, low-stock alerts, and daily business performance summary.
- **🛒 Sales & Billing**: Quick cart additions, barcode/product search, customer ledger, credit sales (Udhar), and instant digital receipts.
- **📦 Inventory Management**: Batch tracking, purchase orders, minimum stock threshold alerts, and reorder reminders.
- **👥 Customer Ledger (Khata)**: Track customer balance, payment history, and send payment reminders.
- **💰 Expense & Profit Tracking**: Categorized business expenses, gross profit vs. net margin analytics.
- **🌐 Bilingual & Multilingual**: Supports English & Tamil (தமிழ்) with instant transliteration and switching.
- **📴 Offline-First**: Powered by Dexie.js (IndexedDB) with local persistence and backup/restore capabilities.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/life-of-abin/Sales-Notes.git
   cd Sales-Notes
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Vanilla CSS (Tailored Design System, Dark Mode & Glassmorphism)
- **Database**: IndexedDB with Dexie.js
- **Icons**: Lucide Icons / SVG System
